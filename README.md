# Resume Builder

Free resume builder with a live A4 preview, three templates (Classic, Modern, Compact), an accent colour picker, a bullet-point checker and PDF download via the browser's print dialog.

- No sign-up and no server: data is saved in the browser (localStorage) and can be exported or imported as a JSON file.
- The checker flags weak openers ("Responsible for…"), first-person bullets, missing numbers, long bullets, thin profiles and short skill lists.
- Plain HTML, CSS and JavaScript, so it deploys as static files on Vercel at no cost.
